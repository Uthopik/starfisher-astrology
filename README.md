# starfisher-astrology
 Feature-rich astrology program

**StarFisher** is primarily designed for use on Windows. I have created an **AppImage** version of the program using **wine.**

[Home page of StarFisher proyect](http://www.starfisher.cz/)

# AppImage version of StarFisher v0.8.5.4 with wine
- **Starfisher-v0.8.5.4-x86_64.AppImage** **[Download](https://github.com/Uthopik/starfisher-astrology/releases/download/v0.8.5.4/Starfisher-v0.8.5.4-x86_64.AppImage)**
- Right-click the **AppImage** file and grant permission via the **‘Permissions’** menu. Alternatively, in the terminal, grant permission using:

```bash
chmod +x ./Starfisher-v0.8.5.4-x86_64.AppImage
```
